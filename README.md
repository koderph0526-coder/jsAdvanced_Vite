# Hei frontendere!

I denne oppgaven skal dere lage en nettside som:

- ..er laget med Vite. Bruk denne kommandoen i terminalen for å lage prosjektet: npm create vite@latest
- ..bruker en selvvalgt npm pakke. Dere kan finne en npm pakke dere synes er interessant, og lese dere opp på dokumentasjonen om hvordan den skal installeres og brukes.

Utover dette kan dere selv velge innhold og utseende på nettsiden, men husk at målet er å bli kjent med Vite/npm og at dette igjen er en mulighet til å lage et prosjekt som kan se bra ut på portfolioen. Derfor anbefaler jeg dere å legge god innsats i prosjektet.

## Npm pakker:

Hvis du er usikker på hvilken pakker du kan bruke har du tre forslag her:

- axios - Axios Npm er en HTTP-klient som forenkler API-forespørsler.
- uuid - genererer unike ID'er (UUID-er) i JavaScript-applikasjoner.
- date-fns - Et verktøysett for å håndtere datoer i JavaScript gjennom nettleser og Node.js.
